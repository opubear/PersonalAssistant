## 自动化验证

运行 `npm run check` 执行类型检查、Node 测试、应用与共享包构建及隔离消费者检查。测试覆盖：

- SQLite 重启持久化与多端版本冲突。
- 批量导入输入校验、事务、去重、人工修改保护、暂停来源、删除后不复活。
- AI 候选与确认数据分离、证据 ID 校验、运行期间证据变更导致整批放弃、无模型显式报错。
- 自动分析失败后持久暂停，手动成功后恢复，避免无限重试。
- 任务批准、原子认领、令牌隔离、结果幂等回报、工作进程失联后不自动重做。
- Codex 系统/工具/推理过滤、事件去重、旧格式回退、App 事件标准化。
- 文件末尾不完整行、失败批次重试、符号链接边界。
- SSH 参数与 stdin 隔离、子进程超时、固定命令 JSON 协议。
- 内置工具文件路径限制、独占写入与幂等行为。
- 后端 bearer 认证、未知方法、bridge Host/Origin 检查。
- 一个真实网关子进程向一个真实监听的本机后端转发请求。
- OpenAI 兼容接口的请求形状、截断/格式/HTTP 错误，以及浏览器原生 fetch 的调用绑定回归。

新增回归覆盖：

- 超时、删除和令牌冲突后的回报归档、同步恢复、不重复执行，以及归档失败的重试。
- 工具下线后的取消、重新选择、状态/版本约束和实际 React 编辑器渲染。
- 损坏/超大文件、服务端永久拒绝的文件隔离；健康文件和任务继续；失败文件不确认且可重试。
- 聊天复合键碰撞、旧索引迁移、空白身份兼容、不同新身份保持区分、手工修改/证据/删除保护。
- 自定义格式及采集器接入、实例状态、未知格式拒绝、请求/结果类型与运行时契约。
- AI 空白标签整批拒绝、旧标签迁移、合法标签规范化，以及同批/已有记忆的去重键碰撞。
- 生产静态首页、SPA 回退、JS 资产、CSP、Host/Origin 校验及非规范路径拒绝；使用真实 HTTP 原始路径避免测试客户端预先规范化。
- Agent 提议状态限制、事务内持久化去重、嵌套对象规范化、人工修改后的重试、删除保护及执行令牌隔离。
