## 三维度改进

- 灵活性：来源格式是可扩展标识；宿主持有 ImportRegistry；核心 AdapterRuntime 仅编排实例，Node 配置工厂负责 I/O 组装；状态来自实际实例。
- 持续集成：四个共享包提供独立 ESM 与类型声明，包级依赖明确；构建按依赖排序；真实 tarball 安装后验证 Node、NodeNext、无 Node 类型的浏览器和浏览器 bundle；CI 配置 Linux/macOS、Node 24 的干净安装与完整检查。
- 清晰度：实体、身份和 RPC 分模块；请求/结果与 handler 返回类型闭环；响应在服务器和客户端校验；bridge 共用 http-support，不依赖 server 应用源码；任务编辑器独立成组件。
