# 桌面前端：截图、资料与手动上传

`Qiyi.app` 是个人助手的 Qt 桌面前端。Qt 界面位于 `apps/desktop/qt`，本地桌面后端位于 `apps/desktop/src`，截图、Agent 会话与资料库组件位于 `apps/capture`。代码、构建和运行均独立于其他项目。无需启动网页、bridge、daemon 或本机服务器即可截图、保存和提问。

## 启动

macOS 双击项目根目录 `start-desktop.command` 或 `Qiyi.app`。同一份资料库只运行一个桌面实例。首次使用截图时，为系统显示的栖忆应用或「栖忆截图服务」授予辅助功能和屏幕录制权限。

运行期间，macOS 屏幕顶部的菜单栏会持续显示栖忆的 Q 形图标；支持系统托盘的其他平台也会显示图标。点击图标可查看本地后端和 Agent 的状态、打开主窗口，或选择「退出栖忆（停止后台服务）」停止后端、截图服务与 Agent。最小化窗口不会隐藏图标。关闭主窗口同样会退出，程序不会在关闭窗口后静默留在后台。不支持系统托盘的环境仍通过主窗口和任务栏显示运行状态。

首次从源码构建：

```sh
npm ci
./build-desktop.sh
./start-desktop.command
```

需要 Node.js 24 或项目支持的更新版本、Swift、Qt 6 Widgets、CMake 与 C++17 编译器。打包包含 Qt 库、Swift helper 和桌面后端 JS；Node.js 使用本机安装。请将 `Qiyi.app` 留在 `personal-assistant` 目录，默认数据位于该目录内的 `data/`。修改源码后重新构建。Swift、Qt 和应用打包的临时产物统一位于 `.local/`。

Linux 可运行 `build-desktop.sh`、`start-desktop.sh`。Windows 可用 Qt/Swift/Node 工具链构建，并通过 Qt 的 `--backend` 与可重复的 `--backend-arg` 指定 Node 和桌面入口。当前仅验证 macOS；Linux/Windows 截图及全局快捷键仍需平台适配，资料导入和记忆接口独立于这些功能。

## 本地与服务器的边界

| 内容 | 默认保存位置 | 如何进入个人助手服务器 |
| --- | --- | --- |
| 截图、Agent 设置、原始截图回复 | `personal-assistant/data/capture/` | 不自动上传 |
| 导入图片、原始文本、资料概述、资料对话 | `personal-assistant/data/capture/library/` | 不自动上传 |
| 新增/确认的个人记忆 | `personal-assistant/data/desktop/local.sqlite` | 用户选择记忆，预览并确认上传 |
| 上传操作的快照、关联关系和回执 | `personal-assistant/data/desktop/uploads/` | 始终留在本地 |
| 服务器记忆、概述和原件 | 服务器 `DATABASE_PATH` 及相邻 `assets/` | 只接收用户确认的上传快照 |

新前端不读取服务器 `.env`，不启动原有采集器/自动分析任务，不扫描或上传旧资料。桌面端与已有网页服务使用独立的本地数据目录，不会把现有服务器数据库复制到本地，也不会改变已有 bridge/daemon 的显式采集配置。

历史截图资料已迁至 `data/capture`，资料 UUID 和个人记忆关联保持不变；索引中的原始截图路径与截图回复的文件位置同步更新。迁移前的数据校验备份位于 `data/migrations/capture-integration-2026-11-16`，无需备份中的文件即可正常运行。迁移没有调用模型或上传内容。

**本地保存不等于本地模型推理。** 启用 Codex、Pi、dsh 后，整理和问答仍会将相应内容发送给该 Agent 配置的模型服务。这与“上传到个人助手服务器”是两个不同动作。

## 使用流程

主界面的「资料与对话」提供可调宽度的资料列表和阅读区；「个人记忆」单独管理本地与服务器记忆。右上角「设置」可展开 Agent 配置、截图权限和本地资料文件夹入口，日常使用时可收起。

1. 在「资料与对话」中按 Control + Option + S 截图，或导入图片、保存文本。
2. 选择资料，点击「整理为个人记忆」。检查并编辑标题、类别、概述、正文和确认状态。原始图片/文本保持关联，保存只影响本地。
3. 也可以在「个人记忆」中直接新增不带原件的本地记忆。AI 资料概述不会自动变成已确认的个人事实。
4. 需要共享时，选择一条**已确认**记忆，点击「上传所选记忆」。预览目标服务器、文字、概述和原件；图片显示预览，文本原件显示完整内容。
5. 点击「确认上传记忆与原件」才发送；取消预览不产生服务器写入。
6. 点击「读取服务器记忆」显式加载服务器列表，选中后可查看关联原件。打开应用或切换标签不自动读取服务器。

持久问答会使用当前本地已确认记忆（最多 30 条）；临时读图只接收固定提示词与当前截图，不接收个人记忆或历史对话。查询不发送到个人助手服务器。服务器列表是管理视图，不自动合并回本地记忆。服务器已有 MCP 继续为其他 Agent 提供已确认的服务器个人上下文。

右上角「设置 → 临时读图 Agent」可独立选择读图程序、参数与 Codex 思考深度，点击「保存读图设置」不启动模型。后续每份截图或导入资料会启动一个临时 Agent，使用固定提示词生成概述，直接写入 `data/capture/library/summaries/<资料 UUID>.md` 后通知资料库刷新。临时 Agent 随后退出，输出不自动进入持久对话。资料详情可以「打开概述文件」。新安装未保存读图设置时只保存原件；旧安装会从原有启动配置生成独立读图配置。

在资料问答顶部点击「启动 Agent」后可发送提问；问答配置改动在启动新会话时生效。持久 Agent 优先查阅概述文件，需要细节或核对原件时才读取对应图片或原文。「停止」只停止持久问答，不影响临时读图；退出软件会停止两者。输入框支持 Command + Enter（其他平台为 Control + Enter）提问，Enter 换行；「保存为资料」随时可用。资料列表显示整理状态、来源与时间；搜索无匹配时可清除搜索恢复列表。图片预览随阅读区宽度等比例缩放，需要细看时可打开原始文件。Agent 回复进度只在有内容时显示。

## 服务器配置

先将服务器更新为本版本并按原部署说明运行 `npm run build`、`npm run start:server`。桌面「服务器设置」填写基础地址和该服务器的管理 `API_TOKEN`（不是功能受限的 `MCP_TOKEN`）。远端必须使用 HTTPS，本机测试可用 `http://127.0.0.1:4310`。反向代理需允许至少 32 MiB 请求体和约两分钟请求时间。

现有 Caddy 模板仅开放 `/mcp`，桌面上传需要访问 `/rpc`。可以为可信设备另行配置 HTTPS `/rpc`，也可沿用 SSH：手动建立 `ssh -N -L 4310:127.0.0.1:4310 your-server`，桌面地址填写 `http://127.0.0.1:4310`，凭证仍使用远端服务器的 `API_TOKEN`。桌面程序不会自行开放端口或修改服务器部署。

凭证仅写入本机 `data/desktop/server-connection.json`，文件权限为 `0600`；不会出现在初始化响应、记忆或上传预览中。同一地址留空凭证表示保留原值。保存设置不进行网络连接。移除连接只删除本机凭证，不删除服务器内容。

没有服务器配置或服务器离线时，本地截图、资料保存、记忆编辑与 Agent 会话仍可使用。服务器地址/凭证变更会使旧上传预览失效，必须重新检查目标。

## 更新、重试和删除

- 上传的是用户确认时的内容快照。修改本地记忆后显示「本地有修改，未上传」，不会后台推送。
- 再次上传已发布记忆时，预览同时显示服务器当前内容；提交使用版本校验，遇到其他设备修改会报冲突，不静默覆盖。
- 网络中断后不会自动重试。再次点击上传会展示上次未完成的原始快照，手动确认后使用同一个操作 ID 重试，避免“服务器写成功但响应丢失”导致重复记忆。
- 删除本地记忆不会删除服务器副本或本地原始资料。删除服务器记忆不会删除本地副本；没有其他服务器记忆引用的原件也会删除。
- 服务器副本被删除后，旧操作不会将它恢复。需要重新发布时，明确新增一条本地记忆再上传。
- 一个记忆可关联一份原始资料。PNG/JPEG 上限 20 MiB；文本原件上限 64 KiB。记忆正文上限 4000 字，概述上限 1200 字。

## 实现边界

Qt 经本机 JSONL 调用 `apps/desktop/src/main.ts`，桌面后端在本机复用 `AssistantService` 管理记忆，并通过 `apps/capture` 构建的 `qiyi-capture-service` 子进程处理截图和资料问答。它不提供任意服务器 RPC 转发；上传必须先产生内容快照再明确提交。平台服务的说明见 [截图组件](capture.md)。

新增服务器 RPC：`memories.list`、`memories.get`、`memories.upload`、`memories.attachment`。上传需要管理身份，未暴露到 MCP 写工具中。原件按 SHA-256 存储；客户端不能指定服务器文件路径。业务 JSON 导出含原件元数据，不内嵌原件字节；完整备份需要同时备份 SQLite 和 `assets/`。

退出桌面应用会停止截图服务及其 Agent。若上传途中退出，操作保持结果未确认状态，下次需手动重试。现有网页、MCP 和独立后台部署入口继续保留。

## 验证

运行 `./test-desktop.sh`。测试使用临时数据库、合成图片、本地测试服务器和模拟 Agent，不读取或上传用户资料。覆盖本地默认不联网、选中上传、原件完整性、重启后显式重试、版本冲突、删除、当前个人上下文和真实 Qt 点击流程。

该脚本也运行 Swift 组件测试和 Python 服务接口测试。Qt 测试环境变量统一使用 `QIYI_` 前缀；具体参数见 `test-desktop.sh`。自定义启动时，`--data-dir` 指定截图资料目录，`--local-dir` 指定本地个人记忆目录，`--no-hotkey` 禁用快捷键注册。

真实远端服务器、账号和在线模型效果不属于这些离线验证；首次真实截图仍需授予 macOS 权限。
