# 项目约定

- 从工程根执行 npm 命令；Node 24 LTS。关键验证入口：npm run check。
- 协议真源在 packages/contracts；浏览器与 Node 适配实现分入口导出，不能将 SSH/文件系统代码打入前端。
- Codex 通过 HTTPS 直接访问后端内置 MCP，不经过 SSH 或本机 MCP 服务。浏览器仍通过仅监听本机的 bridge 访问，网页与适配端可使用既有 SSH 命令网关（不是隧道）。
- AI 结果先进入候选区，不能覆盖人工资料；证据变化必须失效关联资料。自动分析失败持久暂停，不无限请求模型。
- 默认不采集真实目录，不配置模型；测试使用合成数据。所有密钥和运行数据忽略提交。
- 当前是一个人的多设备服务。服务模板、真实远端服务器和模型凭证需要按部署环境配置。
- 首次 Git 提交后需按 AWT 的 execution bind 流程显式延续首次提交前的执行上下文。
